# MedExpiry Frontend

React + TypeScript + Vite UI for medicine package date detection.

## Setup

```bash
cp .env.example .env   # optional
npm install
npm run dev            # http://localhost:5173
```

`VITE_API_URL` defaults to `http://127.0.0.1:8000` (backend). No API keys belong in the frontend.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | ESLint |
